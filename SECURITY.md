# Security Policy

Security reports for NeoDonut Browser should not be sent to the upstream Donut
Browser maintainers unless the issue is confirmed to exist in unmodified
upstream code.

## Reporting a vulnerability

Use the private **Report a vulnerability** form in the Security tab of
`paracosm17/donutbrowser-neo` when available. Do not publish exploit details in
a public issue before a fix is available.

Include:

- affected NeoDonut version and platform;
- reproduction steps or a minimal proof of concept;
- expected impact;
- whether the same behavior occurs in `zhom/donutbrowser`;
- relevant logs with tokens, profile data, cookies, and personal information
  removed.

For non-security bugs, use
[GitHub Issues](https://github.com/paracosm17/donutbrowser-neo/issues).
